# frostming/homebrew-tap

Homebrew tap for my macOS apps.

```sh
brew tap frostming/tap
```

| Cask | Description | Install |
|---|---|---|
| [Cappy](https://github.com/frostming/cappy) | Screenshot tool with annotation, OCR, smart mosaic and decoration | `brew install --cask frostming/tap/cappy` |
| [Xup](https://github.com/frostming/Xup) | Menu bar updater for Homebrew, npm, uv, coding agents and apps | `brew install --cask frostming/tap/xup` |

Both apps are signed with a Developer ID and notarized by Apple.
